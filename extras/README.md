# Extras (not deployed)

Kept for the hackathon show, out of the app proper:

- `stage.html`: audience-demo screen (QR, countdown, random phones become drones, reveal). Paths assume the repo layout (pages at the repo root, this folder beside them).
- `presentations/`: reveal.js deck (PL, EN) and printable cue cards. Radar slides embed the live radar; the stage slide embeds `../stage.html`.
- `deck_facts.js`: Prolog facts for the deck gate (`presentation.pl` in the presentation-builder skill).
- `i18n/`: the translation helpers used to produce the Polish UI; the pages are Polish now, nothing loads these.
